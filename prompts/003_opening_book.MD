# 004 Add Unusual Opening Book

## Date
2026-04-25

## Tool
Claude Code VSCode Extension

## Prompt

Add an unusual opening book to the chess engine. Use niche, uncommon openings (e.g. Grob's Attack, Owen's Defense, Dutch-ish lines) that casual players won't recognize. Key the book on move history tuples so the engine can look up its reply by the sequence of moves played so far.
